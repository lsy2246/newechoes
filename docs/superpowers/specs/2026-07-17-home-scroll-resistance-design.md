# 首页滚动阻力与动画节奏设计

## 背景

首页将约 `620dvh` 的滚动距离线性映射到一条 0–1 的动画进度。当前没有输入速度压缩或区段阻力：滚轮、触控板与触摸滚动造成的页面位移会直接成为动画位移。2D 故事中的部分变化窗口因此可能在一次高速输入内被跳过；3D 房间的可交互窗口只有 0.03 的总进度，约等于 15.6vh，也容易被直接穿过。

## 目标

- 慢速、精细滚动保持接近原生的 1:1 手感。
- 输入速度越高，滚动增量压缩越明显，避免一次输入跨过大段内容。
- 2D 故事的四个主要变化区段获得独立的减速预算，使完整画面有可阅读时间。
- 3D 镜头拉远、可交互、镜头收束和回环收回分别获得合适的进度预算与阻力。
- 桌面端鼠标滚轮、触控板和移动端纵向触摸都采用同一策略，但使用设备相关参数。
- 动画继续读取真实页面滚动位置，避免视觉进度与页面位置分离。

## 非目标

- 不加入章节硬停、滚动吸附或“一次滚轮一幕”的交互。
- 不把动画改成按固定时间自动播放。
- 不改变首页内容、视觉样式或 3D 场景造型。
- 不改变横向拖动 3D 视角的交互含义。

## 方案

### 输入与进度架构

新增纯计算模块 `src/components/home/homeScrollResistance.ts`，负责：

1. 将滚轮的像素、行和页面三种 `deltaMode` 归一化为像素。
2. 根据输入增量、事件间隔、设备类别和当前首页进度计算有效滚动增量。
3. 用平滑区段函数返回当前动画阶段的阻力，不在边界制造手感突变。

`diorama.ts` 负责事件生命周期与滚动副作用。桌面端只在首页动画实际占据视口、事件可取消且不是缩放手势时接管滚轮；它将计算后的有效增量写回真实 `window.scrollY`。键盘滚动、滚动条拖动和程序化滚动仍由现有 `scroll` 监听器直接同步。

移动端在非交互阶段通过单指纵向触摸使用相同计算模块；横向手势不被接管。进入 3D 可交互阶段后，现有手势意图判断继续区分横向环绕与纵向滚动，纵向分支改用受阻增量。

`prefers-reduced-motion`、多指触摸、不可取消事件和 `Ctrl + wheel` 均绕过自定义阻力，保留浏览器原生行为。

### 动态阻力曲线

输入处理分为三层，最终结果保持与原始方向一致：

1. **精细输入保护**：小幅且低速输入基本保持原值。
2. **高速压缩**：超过设备阈值的增量采用次线性曲线压缩；输入越快，额外速度阻力越强。
3. **区段阻力**：仅在输入强度升高时逐渐混入，使慢滚仍然精确，高速滚动在关键画面附近明显变重。

单次有效位移另设视口比例上限，防止异常大的滚轮增量跨越多个故事阶段。桌面和移动端分别调参，移动端上限更小。

初始区段配置按当前动画语义设置：

| 区段 | 总进度 | 目标阻力 |
| --- | ---: | ---: |
| 2D 输入素材成形 | 0.04–0.16 | 1.35× |
| 2D 分类成形 | 0.22–0.41 | 1.45× |
| 2D 项目成形 | 0.40–0.53 | 1.50× |
| 2D 当前状态成形 | 0.56–0.70 | 1.60× |
| 3D 镜头拉远 | 0.70–0.86 | 1.55× |
| 3D 可交互 | 0.86–0.925 | 2.40× |
| 3D 交互收束 | 0.925–0.95 | 1.80× |
| 3D 回环收回 | 0.95–1.00 | 2.00× |

重叠区段取更强阻力，区段起止使用羽化过渡。

### 动画预算调整

- 首页高度从 `620dvh` 调整为 `680dvh`，使整个动画获得约 11.5% 的额外真实滚动距离。
- 2D 故事仍占 0–0.70，但实际滚动距离增加，四个关键变化区段再由动态阻力单独保护。
- 3D 手交接结束点从 0.735 延长到 0.745。
- 房间镜头完成点与交互起点从 0.88 提前到 0.86，为交互窗口让出空间。
- 可交互窗口从 0.88–0.91 扩大为 0.86–0.925；在新高度下约为 37.7vh，超过原来的两倍。
- 交互收束为 0.925–0.95；回环收回为 0.95–0.998，并通过更高阻力增加实际操作时间。

### 生命周期与兼容性

- 所有新增事件监听器都在首页组件清理函数中移除。
- 页面通过 Swup/Astro 返回首页时重新建立状态，不保留上一次手势速度。
- 主题切换继续冻结滚动进度同步，不改变现有主题过渡约束。
- 向上从开场回绕到结尾时保留现有相机预热逻辑；进入回环后续的向上滚动使用区段阻力。
- 当控制器不能安全接管输入时回退到原生滚动，页面仍可访问。

## 测试与验证

- 为归一化、精细输入、高速压缩、区段阻力、单次位移上限和方向保持编写真实函数单元测试。
- 增加集成契约测试，覆盖桌面滚轮、移动端纵向触摸、减少动态效果旁路、监听器清理和新的 3D 预算。
- 运行全部 Node 测试、Astro 类型检查和生产构建。
- 在浏览器中分别用桌面视口与移动视口验证：慢滚跟手、快速滚动不会跨过多个 2D 阶段、可交互 3D 能稳定停留、收束/回环不再瞬间完成、横向拖动仍能环绕。

## 成功标准

- 低速小增量在普通区段的输出与输入近似相等。
- 高速大增量的输出显著小于输入，并受视口比例上限保护。
- 同一高速输入在 3D 可交互区段的有效位移小于 2D 普通区段。
- 鼠标、触控板和移动端纵向手势均无法通过单个异常大事件直接跨过完整可交互窗口。
- 现有首页动画、主题切换、回环、导航返回和减少动态效果测试继续通过。
